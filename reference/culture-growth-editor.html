Using & sharing this file

Save this HTML file, then open it in a desktop browser. Everything runs on your computer. No installation, account or internet connection is needed.

Adjust Growth amount and Shape to create a form, then use Appearance to style it. Export PNG for the displayed appearance or SVG for editable paths.

Your edits last for this open session. Export your assets before closing; reopening the editor starts with the default settings.

To share the tool, send the HTML file itself, or put it in a ZIP. Recipients should download and extract it first, then open the HTML in their browser rather than an email preview.
